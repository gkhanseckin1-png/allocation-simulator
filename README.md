# Allocation & Replenishment Simulator

An interactive retail allocation simulator: one product, 20 stores, a 12-week season.
It compares **equal push** (all stock shipped on day one) with **smart allocation**
(cluster-based initial allocation, weekly replenishment, store-to-store transfers and a markdown rule)
under the same customer demand.

**Live demo:** https://gkhanseckin1-png.github.io/allocation-simulator/

- Synthetic data only. No real company data.
- Single HTML file, no build step, no dependencies.
- Built with AI by Ahmet Gökhan Seçkin.
